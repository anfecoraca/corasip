# Contributing

Thank you for helping. Before you send a change:

1. Open an issue first for anything bigger than a small fix, so we agree on the approach.
2. Keep changes small and focused. Run the tests: the unit tests and the call tests in `tests/` must pass.
3. Do not copy code from any other program. corasip is written from its specification and from observed
   behaviour (see `the private provenance archive (not in this repository)`, which lists facts only).
4. Do not add new dependencies without recording their licence in `docs/SBOM.md` and `NOTICE`.
5. By contributing, you agree that your contribution is licensed under the GNU GPL v3.0 or later, the same licence as
   the project.
